# MZMZ restaurant website

Responsive Arabic/English static website. No build step, package installation, API keys or backend required.

Open `index.html` directly, or serve this folder with any static server. Publish the contents of this folder in the root of a GitHub repository and configure Settings → Pages → Deploy from a branch → main → /(root).

## Content

- Actual restaurant artwork, supplied through Google Drive.
- Arabic/English text switch, persistent in browser storage.
- Menu categories, text search, flavour selector and accessible image dialogs.
- Telephone, Google directions, parking, Instagram and review links.
- Menu and price data are maintained in `app.js`.
- Opening hours follow the supplied graphic: 11 AM–midnight; weekends until 1 AM. Specific weekend days were not supplied, so no live open/closed status is calculated.

The interface and menu descriptions are translated. Original restaurant artwork retains its Arabic lettering.

Original menu artwork is retained. Product cards and enlarged views share tight SVG crops; full menu and chip-flavour sheets open uncropped. The Joy cans are isolated from the existing Joy product image and displayed on the site’s navy/teal palette.
